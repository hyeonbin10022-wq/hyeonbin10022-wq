# 안녕하세요, 👋

**현장의 문제를 코드로 푸는 개발자**입니다.
발파(Blasting) 설계처럼 아직 수작업과 엑셀에 의존하는 산업 현장을 소프트웨어로 바꾸고 있습니다.

## 🚀 대표 프로젝트

### 💥 AeroBlast — 웹 기반 발파 설계 · 시뮬레이션 도구
> 현장 엔지니어가 손으로 하던 발파 설계를 브라우저에서 자동화

- **문제**: 발파공 배치·장약량 계산·진동 검토를 수작업/엑셀로 처리 → 시간 소모, 계산 실수 위험
- **해결**
  - Langefors 공식 기반 **발파 패턴 자동 설계** (저항선·공간격·장약량 자동 계산)
  - 자유면 형상을 따라 발파공을 배치하는 **기하 알고리즘**
  - **뇌관 시차 시뮬레이션** + 지발당 장약량 기반 **발파진동(PPV) 예측 및 안전 판정**
  - 위성지도 위 **2D/3D 시각화**, 벤치 단면 프로파일
- **기술**: JavaScript · Vite · Three.js · Canvas · Supabase
